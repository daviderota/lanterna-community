# Lanterna – labirinti della community

L'editor dei labirinti di **Lanterna – Il Labirinto Oscuro** e i labirinti creati dai giocatori.
The maze editor of **Lanterna – The Dark Maze** and the mazes made by players.

**▶ Apri l'editor / Open the editor:** https://rodaown.github.io/lanterna-community/

## Cosa c'è qui

| | |
|---|---|
| `index.html`, `maze.js`, `whispers.js`, `tiles.png` | l'editor (funziona nel browser, niente da installare) |
| `community/levels/` | i labirinti dei giocatori: regole e istruzioni nel [README della cartella](community/levels/README.md) |
| `.github/` | il controllo automatico delle pull request |

## Proporre un labirinto

Disegnalo con l'editor e premi **Condividi con la community**: si apre GitHub con il file pronto e basta creare la pull request.
Tutti i dettagli in [community/levels/README.md](community/levels/README.md).

Il codice del gioco non è in questo repository.
