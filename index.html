Le misure diventano dispari. Con lo stesso seme esce sempre lo stesso labirinto. Gli anelli aprono alcuni vicoli ciechi e creano più strade possibili. Le gemme finiscono di preferenza in fondo ai vicoli ciechi. Le Ombre stanno ad almeno 12 passi dalla partenza, i falò sono distribuiti lungo il percorso più breve.

Clic o trascina per disegnare. Per spostare la vista: strumento Sposta, barra spaziatrice + trascina, tasto destro, rotellina o due dita. Per lo zoom: Ctrl + rotellina, pizzico o i tasti in basso a destra.

Controllo

    File

    Salva il labirinto sul tuo computer con Salva. Per farlo arrivare agli altri giocatori usa Condividi con la community qui sotto.

    Community

    Proponi il tuo labirinto per la raccolta dei giocatori su GitHub. Serve un account GitHub (è gratis).

    Condividi con la community

    Solo lettere minuscole, numeri e trattini. Diventa .

    1. Si apre GitHub con il labirinto già pronto. Accedi o crea un account.
    2. Se il testo non c'è, incollalo (Ctrl+V o Cmd+V): l'editor l'ha già copiato.
    3. Premi Commit changes… → Propose changes → Create pull request. GitHub fa da solo una tua copia del progetto.
    4. Un controllo automatico prova il labirinto, poi il proprietario lo approva.
